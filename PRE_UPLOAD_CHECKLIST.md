# Pre-Upload Checklist

- [ ] Scientific release verification passes.
- [ ] Secret scan returns zero true secret hits.
- [ ] Personal Windows path scan returns zero hits.
- [ ] No `.ckpt`, `.pt`, `.pth`, or `.env` file is staged.
- [ ] Third-party Git commits and local patches are archived.
- [ ] Checkpoint SHA-256 hashes are archived.
- [ ] Environment snapshots are archived.
- [ ] File inventory and SHA-256 checksums are regenerated after the last edit.
- [ ] README, Data Dictionary, Reproducibility, Model Setup, licenses, and Citation metadata are reviewed.
- [ ] GitHub URL and Zenodo DOI placeholders intentionally remain until public release.
- [ ] Local Git commit exists.
- [ ] No GitHub remote/push has been performed yet.
